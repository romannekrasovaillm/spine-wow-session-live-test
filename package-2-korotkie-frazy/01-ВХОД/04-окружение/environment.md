# Окружение и входные данные второго прогона

## Отличие от первого прогона

| Параметр | Первый прогон | Второй прогон |
|---|---|---|
| Промпты | текст шаблонов P1/P2 из `references/prompts.md` (длинные, со списком полей) | четыре короткие реплики живой речи |
| Состояние `work/` | подложены демо-правила и примеры `bad/good/bypass` | **чистые шаблоны**, ничего не подложено |
| Число шагов | 8 | 4 |
| Отчётов механики | 8 | 13 |
| Вызовов `session.py` | 12 | 20 |

## Версии

| Компонент | Версия |
|---|---|
| Qwen Code | 0.24.4 |

## Как снимались доказательства

Скриншоты — реальные снимки экрана X11 (окно терминала 1854×1048, `mss` + `xdotool`) сразу
после завершения хода агента: слева TUI Qwen Code, справа плашка. Конец хода определялся
по журналу Qwen Code (все вызовы инструментов получили ответ, последняя запись — текст
ассистента, кадр спокоен 40 секунд).
