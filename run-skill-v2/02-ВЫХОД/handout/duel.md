## Кто где сильнее

- **Spine прав, LLM ошибся:** нет
- **LLM прав, Spine ошибся:** C07 (f32 не для денег), C08 (идемпотентность только упомянута в комментарии)

Вывод для архитектора: движок надёжнее там, где проверка формальна и нужна повторяемость, устойчивость к убеждению и полнота на больших файлах. LLM сильнее там, где нужен смысл («это не деньги», «ключа нет, есть только комментарий»). Поэтому LLM формулирует и ревьюит правила, а решает гейт движок.
