# Хук «работа не завершена»

`session.py done-check` возвращает код 2, пока не пройдены `lint-rules`, `selftest` и
`ci-redteam`. Текст причин уходит агенту.

- **Claude Code:** добавьте `claude-code-settings.json` в `.claude/settings.json` рабочей папки
  (путь к скиллу поправьте под свою установку). Stop-хук с кодом 2 не даёт агенту закончить ход.
- **Qwen Code и другие харнессы:** если есть механизм хуков — подключите ту же команду на событие
  завершения хода. Если нет — требование продублировано в SKILL.md: агент обязан запустить
  `done-check` и не объявлять готовность при ненулевом коде.
