# Стандарт платёжного ядра v2 (экспорт Confluence)
## 2.1 Денежные суммы
Денежные суммы не хранятся в типах с плавающей точкой.
## 3.2 Ошибки
Ошибки домена описываются типизированно (thiserror); anyhow и Box<dyn Error> запрещены.
## 4.1 Идемпотентность
Авторизация платежа идемпотентна по ключу.
## 5.1 Техрадар
Библиотеки из зоны HOLD (anyhow, left-pad) не используются.
## 6.1 Наблюдаемость
Каждый сервис публикует метрики по стандарту наблюдаемости.
